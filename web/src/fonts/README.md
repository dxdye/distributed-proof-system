# JetBrains Mono Nerd Font (text font of the web client)

Source: <https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/JetBrainsMono>,
folder `NoLigatures` (no ligatures: in running text `->` or `!=` must stay as typed),
weights Regular 400, Medium 500, SemiBold 600, Bold 700, ExtraBold 800. Licence: SIL Open
Font License 1.1, see `OFL.txt`.

Subset to WOFF2 with fontTools (about 2.4 MB → 37 KB per weight): Latin, Latin-1, Latin
Extended-A, Greek, general punctuation, super- and subscripts, letterlike symbols (ℂ ℕ ℝ),
arrows, mathematical operators, ⟨ ⟩, miscellaneous technical, geometric shapes, ✓ ✗. The
Nerd icons (private use area) are left out; the client does not use them.

Unicode ranges: U+0020-007E, U+00A0-00FF, U+0100-017F, U+0370-03FF, U+2000-206F,
U+2070-209F, U+20AC, U+2100-214F, U+2190-21FF, U+2200-22FF, U+27E8-27E9, U+2300-23FF,
U+25A0-25FF, U+2713-2717, U+2026, U+FFFD.
